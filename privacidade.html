Política de Privacidade

Caderno de Oração

1. Introdução

O aplicativo Caderno de Oração foi desenvolvido para ajudar os usuários a organizar seus pedidos de oração, diário espiritual e lembretes de forma simples, segura e privada.

2. Informações armazenadas

O aplicativo pode armazenar informações fornecidas pelo próprio usuário, como:

  • Nome do solicitante;
  • Telefone (quando informado);
  • Categoria do pedido;
  • Pedidos de oração;
  • Anotações;
  • Diário Espiritual;
  • Fotos;
  • Gravações de áudio;
  • Datas e lembretes.

3. Armazenamento dos dados

As informações permanecem armazenadas no dispositivo do usuário. O aplicativo não vende, compartilha ou comercializa dados pessoais.

4. Permissões utilizadas

Dependendo dos recursos utilizados, o aplicativo poderá solicitar permissões para:

  • Câmera;
  • Galeria;
  • Microfone;
  • Armazenamento;
  • Notificações.

Todas as permissões são utilizadas exclusivamente para o funcionamento dos recursos escolhidos pelo usuário.

5. Compartilhamento de dados

Nenhuma informação é compartilhada com terceiros sem autorização do usuário.

6. Backup

O usuário poderá criar backups dos seus dados. A responsabilidade pela guarda desses arquivos é do próprio usuário.

7. Segurança

São adotadas boas práticas para proteger as informações armazenadas. Apesar disso, nenhum sistema é totalmente imune a riscos.

8. Direitos do usuário

O usuário poderá a qualquer momento:

  • Editar informações;
  • Excluir registros;
  • Criar backup;
  • Restaurar backup;
  • Exportar dados;
  • Desinstalar o aplicativo.

9. Alterações nesta Política

Esta Política poderá ser atualizada sempre que houver alterações importantes no aplicativo.
